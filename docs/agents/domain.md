# Domain Docs

This is a single-context repository.

## Read Before Exploring

- Read root `CONTEXT.md`.
- Read relevant ADRs under `docs/adr/`.
- If either is absent, proceed silently.

## Vocabulary

Use canonical terms from `CONTEXT.md` in tickets, tests, plans, and code. Avoid synonyms listed under `_Avoid_`. Note genuine vocabulary gaps for `/domain-modeling`.

## ADR Conflicts

Surface conflicts with existing ADRs explicitly. Never silently override recorded decisions.
